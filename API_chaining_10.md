Topic 10: API Chaining
----------------------

API chaining means using the output of one API request as the input for another API request.

For example:

1.  Create a user through API 1.

2.  Extract the generated user ID.

3.  Use that user ID in API 2 to fetch the user details.

```
API 1: Create user
       ↓
Extract user ID
       ↓
API 2: Get user using that ID
       ↓
Validate response
```

This is common in real projects because APIs often depend on data created by earlier APIs.

Complete Playwright example
---------------------------

```
import { test, expect } from '@playwright/test';

test("API chaining example", async ({ request }) => {

    // API 1: Create a user
    const createResponse = await request.post(
        'https://jsonplaceholder.typicode.com/users',
        {
            data: {
                name: "Aniket",
                username: "aniketqa",
                email: "aniket@example.com"
            }
        }
    );

    // Validate API 1 response
    expect(createResponse.status()).toBe(201);

    // Read API 1 response body
    const createBody = await createResponse.json();

    // Extract generated user ID
    const userId = createBody.id;

    expect(userId).toBeTruthy();

    console.log("Created user ID:", userId);

    // API 2: Get user using the extracted ID
    const getResponse = await request.get(
        `https://jsonplaceholder.typicode.com/users/${userId}`
    );

    // Validate API 2 response
    expect(getResponse.status()).toBe(200);

    // Read API 2 response body
    const getBody = await getResponse.json();

    // Validate returned user data
    expect(getBody.id).toBe(userId);

    console.log("Fetched user:", getBody);
});
```

Explanation of the workflow
===========================

Step 1: Call API 1
------------------

```
const createResponse = await request.post(
    'https://jsonplaceholder.typicode.com/users',
    {
        data: {
            name: "Aniket",
            username: "aniketqa",
            email: "aniket@example.com"
        }
    }
);
```

This creates a user.

The server may return:

```
{
    "name": "Aniket",
    "username": "aniketqa",
    "email": "aniket@example.com",
    "id": 11
}
```

The `id` is generated by the server.

Step 2: Read the response body
------------------------------

```
const createBody = await createResponse.json();
```

Now `createBody` contains the response JSON:

```
{
    name: "Aniket",
    username: "aniketqa",
    email: "aniket@example.com",
    id: 11
}
```

Step 3: Extract the ID
----------------------

```
const userId = createBody.id;
```

Now:

```
userId = 11;
```

This ID is required by the next API.

Step 4: Use the ID in API 2
---------------------------

```
const getResponse = await request.get(
    `https://jsonplaceholder.typicode.com/users/${userId}`
);
```

Because `userId` is `11`, the actual URL becomes:

```
https://jsonplaceholder.typicode.com/users/11
```

This is API chaining: the response of API 1 controls the request of API 2.

Step 5: Validate API 2
----------------------

```
expect(getResponse.status()).toBe(200);
```

Then:

```
const getBody = await getResponse.json();

expect(getBody.id).toBe(userId);
```

This verifies that API 2 returned the same user that API 1 created.

Another common example: Token chaining
======================================

Authentication is also a form of API chaining.

```
API 1: Login
       ↓
Extract token
       ↓
API 2: Get user details using token
```

Example:

```
const loginResponse = await request.post('/login', {
    data: {
        username: "testuser",
        password: "password123"
    }
});

const loginBody = await loginResponse.json();

const token = loginBody.token;

const profileResponse = await request.get('/profile', {
    headers: {
        Authorization: `Bearer ${token}`
    }
});
```

Here, the token returned by the login API is used in the next API request.

Important interview points
--------------------------

-   API chaining means connecting multiple API requests.

-   The output of one API becomes the input of another API.

-   Common chained values are:

    -   ID

    -   Token

    -   Order number

    -   User ID

    -   Session ID

-   Use `await response.json()` to read the response.

-   Store the required value in a variable.

-   Use that variable in the next request URL, body, or headers.

### Interview answer

> API chaining is a process where we use data received from one API request in another API request. For example, we create a user through a POST API, extract the generated user ID from the response, and use that ID in a GET API to fetch the same user. Tokens from login APIs can also be reused in subsequent authenticated requests.
